BSPI Asset Tag Elements

The real QR code is generated by the system using the selected asset URL/code.
The asset number is dynamic and comes from asset.assetCode.

Final printed tag elements:
1. QR code - generated by JavaScript
2. BSPI logo - assets/images/logos/Asset-logo.png
3. Asset number - dynamic asset code, e.g. SU-0001 or LAPTOP-417

The files tag-template.svg and tag-border.svg are only visual references/placeholders.
